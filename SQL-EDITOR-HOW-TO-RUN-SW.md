# Jinsi ya kuendesha SQL ya SmartNekam kwenye Supabase

1. Fungua `Supabase Dashboard -> SQL Editor`.
2. Chagua `New query` (query mpya tupu).
3. Fungua faili `SMARTNEKAM-INSTITUTION-DIRECTORY-COMPLETE-FIX.sql` kwenye VS Code/Notepad.
4. Nakili faili lote (`Ctrl+A`, kisha `Ctrl+C`) na ubandike kwenye query mpya ya Supabase.
5. Hakikisha mstari wa mwisho unaonekana: `order by type;`
6. Hakikisha hakuna sehemu tu iliyo-highlightiwa; futa selection ikiwa ipo, au bofya ndani ya query bila ku-highlight sehemu.
7. Bonyeza `Run`.

Ikiwa bado inarudisha `syntax error at end of input LINE 0`, mara nyingi query iliyotumwa ni tupu au ni selection isiyokamilika, si faili lote. Usinakili tu sehemu inayoishia kwenye comma. Tuma screenshot inayoonyesha query yote, hasa mistari ya mwisho, na ujumbe kamili wa kosa.
